# Start here

1. Extract this archive completely.
2. On Windows, install Python 3.11 if needed.
3. Double-click SETUP_WINDOWS.bat and wait for dependency installation to finish.
4. Double-click RUN_BASELINE.bat to use the webcam and offline speech.
5. If you want a camera-free software demonstration, use RUN_DEMO.bat.

The baseline recognizes person, chair, bicycle and vehicle. It does not detect the custom stairs/pole/barrier/door classes. Training those requires your annotated dataset and notebook 01. Unknown distance is intentional until you calibrate.

README.md has equivalent PowerShell commands and configuration help. docs/PROJECT_REPORT.md contains the report. docs/Smart_Obstacle_Narrator_Implementation.pptx contains the presentation.

This is an experimental assistive prototype, not a replacement for mobility aids.
